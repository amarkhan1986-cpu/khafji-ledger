KHAFJI LEDGER - PHONE APP (iPhone + Android)

Put it online once (free, about 5 minutes):
1. On a laptop open  https://app.netlify.com/drop
2. Drag this ZIP file (or the unzipped folder) onto the page.
3. Sign up free (Continue with Google) and press "Claim" so the site stays online.
   Unclaimed sites are deleted after about an hour.
4. You get a link like  https://khafji-ledger.netlify.app  (you can rename it in Site settings).

Install on the phone:
- iPhone: open the link in Safari > Share button > Add to Home Screen.
- Android: open the link in Chrome > "Install app" (or menu > Add to Home screen).
Open it once with internet. After that it works with no internet at all.

Updating later: drag the new ZIP onto the same site in Netlify (Deploys > drag and drop).
The phones show "A new version is ready" with an Update button.

Your data (bills, photos, money) is stored only on each phone. The link only gives the empty app.
Use Settings > Backup to save a backup file now and then.
